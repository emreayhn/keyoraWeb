Why Keyora?
  • What if the company shuts down?
  • What if the server gets breached?
  • What if your account is deleted?

Most password managers keep your passwords on their own servers. With Keyora, none of these questions apply to you: your vault never leaves your computer, and its only key is the master password that only you know.

Interface

All your passwords, at a glance.

Simple, fast and keyboard-friendly. Passwords in the list are masked; the eye icon shows one for 10 seconds.

  1. Instant searchFilters as you type an app name, username or category; categories and favorites on the left.
  2. One-click copyUsername or password; whatever you copy is wiped from the clipboard after 20 seconds and never lands in Win+V history.

Features

Everything you expect from a password manager. Except the cloud.

0

Never goes online.

No update checks, no usage statistics, no crash reports. Your vault is a single file on your computer, not tied to any server, account or subscription.

Locks when Windows locks

Win+L, sleep or a dropped remote desktop session lock the vault immediately. It also locks itself when you're idle.

Invisible when screen sharing

Screenshot and recording tools can't see the Keyora window. On by default (before Windows 10 2004 the window shows up black).

20

Clean clipboard

Copied passwords are wiped in 20 seconds and never reach Win+V history or cloud clipboard.

10

Automatic backups

An encrypted backup once a day when you open the vault, and when you lock it after changes. The last 10 are kept by default.

5

Password history

The last 5 passwords of every entry are kept, so you can recover one you changed by mistake.

Strong password generator

Pick the length and character types; passwords come from the operating system's secure random number generator.

Dark and light themes, shortcuts

Switch instantly between pastel dark and light themes. Ctrl+N new entry, Ctrl+G generator, Ctrl+H password health.

Security

How your key is born.

Keyora doesn't invent its own cryptography; it relies on widely used, well-reviewed libraries.

YouMaster password

Never stored anywhere.

Argon2id · salt 1Verification hash

Only answers "is the password right?"

Argon2id · salt 2Encryption key

64 MB memory, 3 passes. Not written to disk.

FernetEncrypted entries

AES-128-CBC + HMAC-SHA256

What's encrypted?

Passwords, app names, usernames, notes and category names. The contents can't be read without your master password.

Brute-force protection

After 3 wrong attempts, the wait grows with each try (up to 5 minutes). Restarting the app doesn't reset it.

Open source

All of the code is on GitHub. Anyone can read and audit what it does.

By design: if you forget your master password, your vault cannot be opened in any way. There is no recovery email and no back door. Keep your master password somewhere safe.

FAQ

Questions, answered

Where is my data stored?

Your vault lives in %LOCALAPPDATA%\Keyora\keyora.db, inside your Windows user folder. Wherever you install the app, it uses the same file. Your entries are encrypted and can't be read without your master password.

Is there cloud sync or a phone app?

No, on purpose. The point of Keyora is that your passwords never leave your computer. To move to another computer, carry a backup file over yourself: install Keyora there, create a temporary vault, then restore the backup from Ayarlar → Yedekleme → Yedekten Geri Yükle (Settings → Backup → Restore from Backup). The restored vault opens with the master password it had when the backup was made.

Windows warns about an "unknown publisher". Is it safe?

The warning appears because the file isn't signed with a paid code-signing certificate; it says nothing about the app itself. Choose "More info → Run anyway" to continue. The full source code is public on GitHub.

Will uninstalling delete my passwords?

No. Uninstalling removes only the program; your vault and backups stay where they are, and reinstalling opens the same vault. To remove everything, delete the %LOCALAPPDATA%\Keyora folder yourself. If you chose a different backup folder in Settings, delete that too.

I use Keyora 1.0.0. How do I upgrade?

Just run the new installer; your vault is found automatically. On first sign-in it's converted to the new format, and a backup is made automatically before the conversion. Afterwards, delete any old 1.0.0 exe copies, since the old version can't read the converted vault correctly. The pre-conversion backup is in the old format, so its app names, usernames, notes and category names are in plain text; once you're happy with the new version, delete it from Ayarlar → Yedekleme → Eski Yedeği Sil (Settings → Backup → Delete Old Backup).

Can I store two-factor (2FA) codes?

No. Keeping passwords and 2FA codes in the same place defeats the purpose of the second factor. That's why 2FA codes are deliberately left out when importing, and Keyora tells you how many were skipped.

Does it cost anything? Any ads or data collection?

Keyora is free and open source under the MIT license. It has no ads, collects no data and never goes online. This page has no ads or visitor-tracking scripts either.
